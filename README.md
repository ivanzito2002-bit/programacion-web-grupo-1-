PROYECTO=
---------------------------------------------------------------------------------------
Este proyecto consiste en el desarrollo de una página web orientada a una marca de impresiones 3D.

El objetivo principal fue aplicar los conocimientos básicos de desarrollo web utilizando Visual Studio Code, integrando estructura, diseño y contenido en una página funcional.

La web presenta información sobre los servicios de impresión 3D, mostrando de manera clara y accesible las posibilidades que ofrece esta tecnología, incluyendo ejemplos de productos, descripción de servicios y datos de contacto.
